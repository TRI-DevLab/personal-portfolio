# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my projects, technical skills, certifications, and professional journey as an aspiring software engineer.

## About

This portfolio serves as a central hub for my work and achievements. It highlights my software development projects, academic journey, and ongoing learning while providing an easy way for visitors to learn more about me and get in touch.

The website is designed to grow alongside my experience, with new projects, certifications, and accomplishments added over time.

## Features

* Responsive design for desktop, tablet, and mobile
* Modern and clean user interface
* About Me section
* Skills and technologies
* Project showcase
* Education and certifications
* Contact information
* Downloadable résumé/CV
* Links to GitHub and LinkedIn
